Git Cyclone Source code

Personal Git manager

Every Git repository on your computer in one window. See what changed, commit and push, without typing commands.

Download View on GitHub

Free and open source. For Windows 10/11 and Linux.

What it does

Git Cyclone runs the git already installed on your computer, so everything behaves the same as in the terminal.

  • All your repositories at a glance

    Point it at your projects folder. Each repository shows its branch, unsaved changes and whether it is ahead of or behind the remote.

  • History you can read

    A commit graph with branches, merges and tags. Click a commit to see its files, click a file to see what changed.

  • Commit exactly what you mean

    Stage whole files, single blocks or individual lines, then commit, amend, or commit and push in one step.

  • Branches and conflicts

    Create, merge, rebase and stash from the sidebar. When a merge conflicts, pick your side, theirs or both, block by block.

  • Your accounts stay where they are

    Push and pull use Git Credential Manager and your SSH keys. Git Cyclone stores no passwords or tokens, and lets you choose an account per repository.

  • Hard to lose work

    Discarded changes are backed up first, a hard reset stashes your work, and force push never overwrites commits you have not seen.

Get Git Cyclone

Installers for Windows (.exe, .msi) and Linux (.deb, .rpm, AppImage). You need git installed.
